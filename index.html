1. What Are Cookies and Similar Technologies

Cookies are small text files a website can store in your browser. Similar technologies include "local storage" and "session storage," which websites use in much the same way, to remember information between visits.

2. What Tradelify Actually Uses Today

Tradelify does not currently set traditional cookies, and does not use any third-party advertising or cross-site tracking cookies. What the Platform does use is your browser's local storage, for the following strictly functional purposes:

  • Authentication (essential): Google Firebase Authentication uses browser storage to keep you signed in between visits.
  • Preferences (functional): your dark/light theme choice is saved so it applies automatically next time.
  • Referral tracking (functional): if you arrive via a referral link, the referral code is temporarily stored so it can be credited correctly if you sign up.

Tradelify does not currently use analytics, performance-measurement, or advertising cookies of any kind.

3. Consent

Because the storage described above is limited to essential authentication and basic functional preferences — and does not include analytics, advertising, or cross-site tracking — the Platform does not currently display a cookie consent banner. If Tradelify introduces analytics or advertising cookies in the future, this policy will be updated and an appropriate consent mechanism (allowing you to accept, reject, or manage preferences) will be implemented before such cookies are used.

4. Third-Party Embeds

5. Managing Storage
